# 高専シラバス 評価プランナー

豊田工業高等専門学校・情報工学科の公開Webシラバスから評価割合を取得し、A/B/C/F評価に必要な残りの定期試験得点を逆算する非公式ツールです。

## 主な機能

- 2026年度の科目を、単位数・学年・学期・必修／選択・必履修・評価割合つきの一覧で比較
- 科目名・教員名・科目番号で検索し、学年は1クリックで絞り込み
- シラバス記載の評価割合を科目ごとに表示
- 通常は獲得点だけ入力すれば即時計算（A/B/C/F基準と試験条件は必要な場合だけ展開して編集）
- 課題・小テスト・中間試験など、獲得済みの素点と配点割合を複数入力
- 残りの試験で必要な得点を、試験満点と得点刻みに合わせて切り上げ表示
- 「到達済み」「満点でも到達困難」を判定
- 公式シラバスを計算画面の横（スマートフォンでは下）にそのまま表示
- 入力内容を科目ごとにブラウザ内へ自動保存

## ローカルで動かす

Node.js 22以降を用意して、次を実行します。

```bash
npm install
npm run scrape
npm run dev
```

表示されたローカルURLを開いてください。テストと本番ビルドは次のコマンドです。

```bash
npm run check
```

## 計算方法

獲得済み項目の総合点への加重点を次で求めます。

```text
獲得済み総合点 = Σ（項目の評価割合 × 獲得点 ÷ 項目の満点）
必要試験得点 =（評価基準 − 獲得済み総合点）× 試験満点 ÷ 今回の試験割合
```

必要得点は指定した得点刻み（初期値1点）へ切り上げます。最終総合点の四捨五入は行いません。

## GitHub Pagesへ無料デプロイ

1. このフォルダをGitHubリポジトリの `main` ブランチへpushします。
2. GitHubの **Settings → Pages → Build and deployment** で Source を **GitHub Actions** にします。
3. `Scrape syllabus and deploy Pages` ワークフローの完了を待ちます。

以後、`main` へのpushで自動デプロイされます。毎週月曜早朝（日本時間）と手動実行時にはシラバスも再取得します。更新されたJSONをリポジトリへ残したい場合は、ローカルで `npm run scrape` を実行して `src/data/subjects.json` をcommitしてください。

## データ取得方針と制約

GitHub PagesのブラウザJavaScriptから公式サイトへ直接アクセスするとCORS制約を受けるため、シラバスはビルド前に取得して必要最小限の事実データだけをJSON化しています。144ページへ過度な負荷をかけないよう、低い並列数とリクエスト間隔、週1回の更新にしています。

公式ページは現時点でiframe表示を禁止するレスポンスヘッダーを返していませんが、将来の設定変更により埋め込み表示できなくなる可能性があります。その場合も「別タブで開く」リンクは利用できます。クロスオリジン制約により、iframeの中へ直接入力欄を注入しているわけではありません。

シラバスの「定期試験65%」などは複数回の試験合計である場合があります。1回分の割合を自動推測できないため、計算時の「今回の試験が総合評価に占める割合」は必ず授業の説明に合わせて調整してください。最終的な評価基準・丸め・追試等は担当教員と[公式Webシラバス](https://syllabus.kosen-k.go.jp/)で確認してください。
