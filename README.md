# 高専シラバス 評価プランナー

豊田工業高等専門学校の本科5学科（機械、電気・電子システム、情報、環境都市、建築）の公開Webシラバスから評価割合を取得し、A/B/C/F評価に必要な残りの定期試験得点を逆算する非公式ツールです。他高専や専攻科は対象にしていません。

## 主な機能

- 学科を一覧上部で切り替え、2026年度の科目を単位数・学年・学期・必修／選択・必履修・評価割合つきで比較
- 科目名・教員名・科目番号で検索し、学年は1クリックで絞り込み
- シラバス記載の評価割合を科目ごとに表示
- 科目一覧を表計算シートとして使い、ページ移動なしで必要点を計算
- 課題・小テスト・中間試験など、シラバス記載の各項目へ得点と満点を直接入力
- A/B/C/F基準は一覧上部で一度設定し、全科目へ適用
- 残りの試験で必要な得点を、試験満点と得点刻みに合わせて切り上げ表示
- 「到達済み」「満点でも到達困難」を判定
- 各行から公式シラバスを別タブで確認
- 入力内容を科目ごとにブラウザ内へ自動保存

## ローカルで動かす

Node.js 22以降を用意して、次を実行します。

```bash
npm install
npm run scrape
npm run dev
```

表示されたローカルURLを開いてください。テストと本番ビルドは次のコマンドです。

```bash
npm run check
```

## 計算方法

獲得済み項目の総合点への加重点を次で求めます。

```text
獲得済み総合点 = Σ（項目の評価割合 × 獲得点 ÷ 項目の満点）
必要試験得点 =（評価基準 − 獲得済み総合点）× 試験満点 ÷ 今回の試験割合
```

必要得点は指定した得点刻み（初期値1点）へ切り上げます。最終総合点は小数点以下を切り捨てて評価判定します。

## GitHub Pagesへ無料デプロイ

1. このフォルダをGitHubリポジトリの `main` ブランチへpushします。
2. GitHubの **Settings → Pages → Build and deployment** で Source を **GitHub Actions** にします。
3. `Scrape syllabus and deploy Pages` ワークフローの完了を待ちます。

以後、`main` へのpushで自動デプロイされます。毎週月曜早朝（日本時間）と手動実行時にはシラバスも再取得します。更新されたJSONをリポジトリへ残したい場合は、ローカルで `npm run scrape` を実行して `src/data/subjects.json` をcommitしてください。

## データ取得方針と制約

GitHub PagesのブラウザJavaScriptから公式サイトへ直接アクセスするとCORS制約を受けるため、シラバスはビルド前に取得して必要最小限の事実データだけをJSON化しています。公式サイトへ過度な負荷をかけないよう、低い並列数とリクエスト間隔、週1回の更新にしています。取得対象は `school_id=23` の本科5学科に固定しています。

公式サイトとはクロスオリジンのため、一覧では取得済みの必要最小限のデータだけを使い、原文は各科目行の外部リンクから確認できるようにしています。

シラバスの「定期試験65%」などは複数回の試験合計である場合があります。1回分の割合を自動推測できないため、計算時の「今回の試験が総合評価に占める割合」は必ず授業の説明に合わせて調整してください。最終的な評価基準・丸め・追試等は担当教員と[公式Webシラバス](https://syllabus.kosen-k.go.jp/)で確認してください。
